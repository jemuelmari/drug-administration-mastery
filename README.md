## ✨ Features

### Student App (`index.html`)
- 📚 **12 Learning Units** — Foundations, Ethics, Nursing Process, 10 Rights, Orders, Oral/Topical, Eye/Ear, ID/SC/IM, IV, Preparation, Calculations, Documentation
- 🎮 **5 Mastery Games** — Route Racer, Right or Wrong, Dosage Duel, Order Interpreter, Safety Scanner
- 💊 **Drug Database** — 50 drugs with high-alert flagging
- 🧮 **Dosage Calculator** — Formula: Desired ÷ Stock × Volume
- 📋 **MAR Practice Simulator** — Transcribe physician orders
- ✅ **Return Demo Checklists** — Self-check + Instructor verification (Oral/Topical and Parenteral)
- 📝 **Capstone Exam** — 30 NLE-aligned items (includes dosage calculations)
- 🏆 **Leaderboard** — Anonymous ranking
- 🏅 **Certificate of Mastery** — Printable upon passing
- 📬 **Instructor Feedback Inbox** — Receive messages from instructor
- 📱 **Offline-First PWA** — Works without internet after first load

### Instructor Dashboard (`instructor-dashboard.html`)
- 📊 Overview with class stats
- 📥 Import students by code (format: `DA-XXXX-XXXX`)
- 👥 Full roster with search
- ☁️ Bulk sync from Google Sheets
- 💬 Send feedback to students
- 🔓 Grant retake codes

### Gradebook (`gradebook.html`)
- 📊 Class record with automatic computation
- 🏆 Philippine transmutation table
- ⚖️ Configurable weights
- 📤 CSV export
- 🖨️ Print-optimized layout
- ✍️ Signature blocks
